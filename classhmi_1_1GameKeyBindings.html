Detailed Description

Association action de jeu -> touche, avec persistance JSON (EX-CTRL-012, LOT-29).

Une touche par action ; setKey échange automatiquement avec toute autre action qui détenait déjà cette touche, pour ne jamais laisser deux actions du jeu sur la même touche. load/save partagent un seul fichier avec EditorKeyBindings (section "jeu", l'autre classe possédant sa propre section "editeur" du même fichier, sans interférence) : chaque sauvegarde relit puis fusionne, plutôt que d'écraser tout le fichier.
