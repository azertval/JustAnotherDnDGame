Detailed Description

Tests de l'atlas des régions (LOT-37) : les treize régions chargent, le graphe tient, et trois encarts sont rejoués contre des valeurs RECOPIEES A LA MAIN du Sourcebook.

Le dernier point est l'acceptation du lot, et sa forme n'est pas negociable : les notes ci-dessous ont ete lues sur le PDF, page imprimee a l'appui, et non copiees depuis le JSON produit. Un test qui comparerait la sortie de l'extraction a elle-meme passerait quelle que soit la faute – et la faute a redouter ici est precisement silencieuse : une valeur juste rangee dans le mauvais axe.
