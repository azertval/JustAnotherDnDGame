AlphaOverEstAssociatif  )

L'alpha-over est associatif : aplatir trois couches d'un coup donne le même résultat que deux fois deux — sans quoi l'ordre d'aplatissement changerait l'image.

Cas de test : L'alpha-over est associatif.
Categorie : Unitaire · Reference de plan
Criticite : Critique
Etapes :
1. Composer trois pixels semi-transparents en groupant a gauche, puis a droite.
Resultat attendu : Les deux resultats coincident.
