TEST ( PlaneFileNamingTest ,
CaracteresRefusesRetires  )

Les caractères refusés sont retirés, l'espace devient un tiret, et les tirets de bord disparaissent — un nom qui perd ses accents reste lisible.

Cas de test : Les caracteres refuses sont retires du nom de plan.
Categorie : Unitaire · Nommage des plans
Criticite : Majeur
Etapes :
1. Assainir des noms contenant espaces, accents, ponctuation et tirets de bord.
Resultat attendu : Seuls lettres, chiffres, tiret et tiret bas subsistent, sans tiret aux extremites.

TEST ( PlaneFileNamingTest ,
DensiteOuTailleInvalideRefusee  )

Une densité hors format ou une taille dégénérée ne produit aucune dimension : mieux vaut refuser que créer un fichier d'une taille que rien ne saura relire.

Cas de test : Une densite ou une taille invalide ne produit aucune dimension.
Categorie : Unitaire · Nommage des plans
Criticite : Majeur
Etapes :
1. Deriver les dimensions avec une densite hors format, puis avec une largeur nulle.
Resultat attendu : Les deux renvoient des dimensions nulles.

Le nom dérive de celui du niveau, et un suffixe numérique croissant le rend unique.

Cas de test : Le nom d'un plan est unique par suffixe numerique croissant.
Categorie : Unitaire · Nommage des plans
