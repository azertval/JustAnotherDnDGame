Detailed Description

Une rencontre, telle que la donnée la décrit.

Aucune position absolue, aucune carte nommée : une rencontre dit qui et en quelle formation, pas où. C'est le déclencheur qui apporte le lieu.

bool core::Encounter::escapable = true

Vrai si le joueur peut fuir cette rencontre.

Une rencontre dont on ne peut pas fuir est une décision de contenu — un combat de scénario —, et elle est donc écrite dans la donnée plutôt que devinée d'un type d'ennemi. Par défaut on fuit : l'inverse enfermerait le joueur dans toute rencontre qu'un auteur aurait oublié de renseigner.
