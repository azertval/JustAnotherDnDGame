Detailed Description

Métriques d'une police bitmap : région et avance de chaque point de code couvert.

Donnée pure (EX-NFR-010) : ne référence ni fichier ni GPU, seulement ce qu'il faut pour mesurer et composer du texte en quads. Un point de code absent retombe sur replacementCodePoint (substitution déterministe, EX-NFR-040) — jamais un trou silencieux ni un plantage.
