Detailed Description

Garde de fichier modifié sur disque (EX-EDIT-057).

Une carte ouverte peut changer sous l'éditeur : un script la régénère, Claude la retouche, un git checkout la remplace. L'éditeur retient l'empreinte du fichier qu'il a lu ou écrit, et la compare à celle du disque quand le fichier est signalé changé, quand la fenêtre reprend la main et avant chaque enregistrement. Une carte n'est jamais écrasée en silence.

L'empreinte porte sur le contenu, pas sur la date : un fichier réécrit à l'identique n'est pas un changement, et une date qui recule (restauration) n'en cache pas un.
