Detailed Description

Dessine un core::LevelDraft en cours d'édition, à plat.

Une couleur par type de tuile (hmi::regionForTile, l'atlas procédural), les couches visuelles dans leur ordre, la collision en masque teinté par catégorie, puis les entités par leur marqueur de famille (LOT-39). Le canevas ne cherche pas à ressembler au jeu : il montre ce qu'on édite — le type de chaque case — et l'essai immédiat montre le jeu (hmi::EditorViewport).

Toutes les primitives d'une image sont composées dans une seule hmi::ComposedScene puis soumises en bloc : les aides d'édition portent le calque RenderLayer::EditorOverlay, qui les place au-dessus du reste par construction. La liste obtenue est inspectable sans GPU (EX-NFR-004).
