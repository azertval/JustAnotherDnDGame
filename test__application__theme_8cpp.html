TEST ( ApplicationThemeTest ,
ResolutionDePoliceSansNomDeRepliCodeEnDur  )

La police embarquée est retenue quand elle a pu être enregistrée ; sinon, aucun nom de famille n'est renvoyé (TACHE-03) – l'appelant Qt doit alors demander une famille générique, jamais un second nom codé en dur.

Cas de test : La resolution de police retombe sur une famille generique sans nom code en dur.
Categorie : Unitaire · Theme de l'IHM
Criticite : Critique
Etapes :
1. Resoudre la police embarquee enregistree, puis non enregistree.
Resultat attendu : Le premier cas rend la famille embarquee ; le second ne rend aucun nom de famille.
