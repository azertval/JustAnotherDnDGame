Zoom rationnel (LOT-69 TACHE-07) : l'aller-retour vue ↔ image reste exact aux dénominateurs 2 et 4, c'est-à-dire sous le 1:1.

L'extension est compatible par construction — le dénominateur vaut 1 par défaut, et tous les cas ci-dessus, écrits avant elle, valent tels quels. Ce test-ci couvre le terrain nouveau. Cas de test : L'aller-retour vue vers image reste exact sous le 1:1.
Categorie : Unitaire · Geometrie du canevas pixel
Criticite : Critique
Etapes :
1. Pour les denominateurs 2 et 4, convertir chaque pixel image en rectangle ecran.

  1. Reconvertir le centre de ce rectangle en pixel image.
    Resultat attendu : Le pixel de depart est retrouve a chaque fois.

TEST ( PixelCanvasGeometryTest ,
ScreenToImagePixelPourDiversesVues  )

Pour une combinaison de zoom et de décalage de vue, la position de souris donne le bon pixel image.

La conversion ne dépend jamais de l'échelle d'affichage : Qt livre déjà les positions de souris en pixels logiques, indépendamment du devicePixelRatio. Cas de test : screenToImagePixel donne le bon pixel pour diverses combinaisons de zoom et de decalage.
Categorie : Unitaire · Geometrie du canevas pixel
Criticite : Critique
Etapes :
1. Construire plusieurs vues (zoom, decalage) differentes.
2. Convertir une position ecran connue vers un pixel image.
Resultat attendu : Le pixel obtenu correspond a la case ecran attendue dans chaque cas.
