Detailed Description

Charge une séquence de niveaux au format JSON ({version, titleKey, levels: [...]}), EX-LVL-013.

Ne lève aucune exception vers l'appelant (EX-NFR-040) : toute erreur (JSON malformé, champ manquant, liste vide, version non gérée) est renvoyée dans le LevelSequenceLoadResult.
