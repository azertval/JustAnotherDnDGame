Detailed Description

Le détail d'un lancer, pour que le joueur puisse le reconstituer (EX-DND-003).

Chaque dé est conservé, pas seulement le total. Un jeu de rôle au dé dont le joueur ne peut pas reconstituer pourquoi il a échoué se joue comme une machine à sous — et c'est aussi le seul outil de diagnostic praticable quand une capacité ne s'applique pas.
