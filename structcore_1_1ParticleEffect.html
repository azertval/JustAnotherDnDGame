Detailed Description

Données décrivant un effet de particules : combien, à quelle vitesse, pendant combien de temps, avec quelle dispersion angulaire – en constantes nommées côté appelant, jamais de nombres magiques dispersés dans le code (LOT-53 TACHE-01).
