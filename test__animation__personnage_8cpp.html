Detailed Description

Tests d'intégration de l'animation du personnage : ECS + système d'animation assemblés.

AnimationSystem dérive le clip (idle/run/jump) et l'image courante de l'état physique du personnage (Player::grounded, Velocity). Test de référence (LOT-46 TACHE-04) : la migration vers le moteur générique piloté par données ne doit produire aucune différence de comportement — mêmes attentes qu'avant le lot, exprimées avec la nouvelle API (clipIndex résolu dans core::playerClipSet(), plutôt que l'ancien enum class core::AnimationClip).
