Detailed Description

Amorçage partagé par les deux applications (LOT-86).

Depuis que le jeu et l'éditeur sont deux binaires distincts, la journalisation, le niveau de log et les traductions de Qt lui-même sont les seules choses qu'ils font à l'identique. Les écrire ici plutôt que deux fois évite qu'elles divergent — un défaut qui ne se verrait qu'en lisant les deux fichiers côte à côte.

Ce qui n'est pas ici : le style, le thème, la fenêtre. Ce sont précisément les points où les deux applications diffèrent, et les mettre en commun demanderait un paramètre par différence.
