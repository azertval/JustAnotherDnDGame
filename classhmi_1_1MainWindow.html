Detailed Description

Fenêtre principale de l'éditeur (Qt Widgets).

Le canevas (hmi::EditorViewport) est le widget central ; la palette, le navigateur de cartes, les couches et les entités sont des docks détachables dont la disposition est persistée (EX-IHM-010/011). La fenêtre ne possède aucune donnée d'édition : le canevas est le seul propriétaire du brouillon, les panneaux demandent et il applique.
